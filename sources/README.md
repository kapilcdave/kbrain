# Sources and Provenance

This repository distinguishes public sources from private provenance.

## Public Sources

Pages link directly to repositories and documentation that were already
intentionally public. Those projects retain their own licenses.

## Private Research Archives

Some syntheses were derived from private research repositories built from public
market data. Frontmatter identifies those archives with values such as
`private:weather`. This is a provenance marker, not a public URL or an offer to
redistribute the underlying raw data.

## Third-Party Work

Reference repositories, upstream thesis code, vendor data, and external
documentation are not claimed as original work. No third-party repository or
dataset was copied into `kbrain`.

## Citation Standard

Public claims should prefer primary documentation and public source code. Where
the reproducible artifact remains private, the page says so and limits itself to
a high-level aggregate conclusion.
