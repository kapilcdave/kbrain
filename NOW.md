# Now

_Updated September 3, 2026._

## Current Focus

- Turning model-gateway telemetry into privacy-preserving compute-exposure
  measurements through [Hedge Router](projects/hedge-router.md).
- Exploring shared intent and memory for parallel coding agents through
  [Agent Memory Coordination](projects/agent-memory-coordination.md).
- Consolidating quantitative research into reusable methodology instead of
  continuing to search the same closed strategy families.
- Publishing the strongest lessons from failed and corrected experiments.

## Questions I Care About

- How should several stochastic agents coordinate before their tool calls
  collide?
- Can operational telemetry describe a real economic exposure without storing
  prompts, code, or user identity?
- What evidence should be required before a statistically interesting result is
  allowed near production?
- How can negative results remain useful and searchable rather than disappear?

## Not Doing

- Treating private operational logs as public content.
- Calling an indicative price or paper fill an executable result.
- Reopening frozen studies without a changed mechanism and a new evaluation
  window.
