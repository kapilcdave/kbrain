# Khermes (`@kapilebot`)

## Summary

Khermes is Kapil Dave's Hermes Agent available on Telegram as
[@kapilebot](https://t.me/kapilebot). It is separate from the Hermes agent at
`@kapilubot`; both agents report durable work into kbrain.

## Role

Khermes is an execution agent, research collaborator, coding agent, and
continuity layer. It can operate tools, verify changes, maintain reusable
procedures, and promote reviewed public lessons into kbrain.

## Public Artifacts

Khermes owns [`agents/kapilebot/`](../agents/kapilebot/README.md), including its
identity, behavior, capability inventory, memory and security policies, and four
published workflow skills.

## Multi-Agent Context

The full roster and shared rules are in [`agents/`](../agents/README.md). Agent
identity and provenance remain separate even when several agents contribute to
the same project or repository.

## Publication Boundary

The live Hermes home contains credentials, sessions, connector state, logs, and
other private or ephemeral material. Kbrain contains only an allowlisted,
rewritten projection. Raw runtime state is never mirrored here.
