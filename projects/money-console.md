# Money Console

## Summary

A small local browser tool for exploring household cash flow and possible
income scenarios without sending financial inputs to a server.

## What I Built

The application is plain HTML, CSS, and JavaScript. It stores data in browser
local storage, supports JSON import and export, ranks income opportunities, and
draws cash projections over configurable horizons.

## What I Learned

For personal tools, deployment and account systems can be unnecessary surface
area. A single local document with a clear export path can provide useful
software while keeping financial inputs on the user's machine.

## Current Status

Private local utility. This page describes its design without publishing user
data or snapshots.
