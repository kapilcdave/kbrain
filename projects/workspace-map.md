# Workspace Map

The local workspace is a collection of independent Git repositories, derived
trees, private research archives, public products, and reference material. It
is not one monolithic project. Private directory and deployment names are
intentionally omitted.

| Area | Role | Public treatment |
|---|---|---|
| Agent coordination | Shared state and intent prototype | Dedicated page and public source link |
| Compute exposure | Hedge Router development | Dedicated page and public source link |
| Market terminal | Read-only comparison product | Dedicated page and public source link |
| Scheduling | Availability product | Dedicated page and public source link |
| Personal site | Static site and writing | Linked from About |
| Narrative analysis | Filing and news pipeline | Dedicated page and public source link |
| Options | Research and paper tooling | Dedicated page and public source link |
| Weather | Research archive plus a historical derived runner | Sanitized synthesis; derived tree not counted twice |

| Crypto | DEX, carry, options, and microstructure | Sanitized synthesis only |
| Baseball | Application work plus upstream thesis code | Attribution required; upstream work not copied |
| Machine-learning reference | Third-party book repository | Explicitly not claimed as original work |
| Empty placeholders | Reserved names without implementation | No project claim |

Generated data, virtual environments, build outputs, runtime state, logs, and
nested duplicate repositories are excluded from this public knowledge base.
