# Earlier Builds

Before the current research systems, I built across several domains:

- [BearCourses](https://github.com/kapilcdave/berkeleycourseai), a multi-agent
  course-selection project.
- [Quarterzip Detector](https://github.com/kapilcdave/camera_detect), a YOLOv8
  computer-vision experiment.
- [Hoodly](https://github.com/kapilcdave/Hoodly-2.0), an AI-assisted navigation
  project focused on Berkeley.
- [Kite Flier Simulator](https://github.com/kapilcdave/KiteFlyerSimulator), a
  browser-based physical simulation.
- [Fortnite 2D](https://github.com/kapilcdave/fortnite2d), a two-dimensional
  sandbox shooter.
- [Poker Practice Bot](https://github.com/kapilcdave/Poker-Practice-Bot), a
  React poker simulation.
- [CS61A work](https://github.com/kapilcdave/CS61A) and a
  [Scheme contest entry](https://github.com/kapilcdave/kapil-s-sheme-contest-submission).

These repositories document learning by building. Where no retrospective or
maintenance evidence exists, this page does not invent one.
