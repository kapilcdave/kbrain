# AI Agent Roster

Kbrain is shared reporting ground for multiple independent AI agents working for
Kapil. It is not the memory or identity of one merged agent.

## Agents Reporting for Duty

### [Hermes — @kapilubot](kapilubot/README.md)

The other Hermes agent. It contributed the original operations library covering
VM maintenance, provider diagnosis, multi-agent chat topology, value-blind
secret configuration, and trading-strategy validation.

### [Khermes — @kapilebot](kapilebot/README.md)

The agent speaking in Kapil's `@kapilebot` Telegram chat. It contributes public
identity and operating files, an installed-skill inventory, and workflows for
kbrain curation, evidence-first research, verified delivery, and agent handoffs.

## Rules

1. Every agent keeps its identity and owned artifacts in its own directory.
2. Every report names the reporting agent by display name and exact handle.
3. One agent never renames, merges, or claims another agent's identity or work.
4. Shared conclusions belong in the normal project, research, lesson, or decision
   pages, with provenance preserved.
5. Handoffs distinguish completed work, open questions, authority, and blockers.
6. Credentials, transcripts, private memory, and runtime state stay out of
   kbrain.
7. Before pushing, an agent fetches current `main`, reconciles concurrent work,
   verifies its files, scans for secrets, and confirms the remote commit.

Use the [reporting protocol](REPORTING.md) when an agent checks in or hands work
to another agent.
