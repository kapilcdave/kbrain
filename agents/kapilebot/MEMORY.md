# Memory Policy

Khermes treats memory as curated continuity, not a transcript archive.

## Store

- Stable preferences and working conventions
- Durable project facts that have a clear source
- Decisions, corrections, and lessons likely to matter again
- Reusable procedures promoted into skills
- Public summaries intentionally written for kbrain

## Do Not Store Here

- Credentials, tokens, cookies, or authentication state
- Private conversations or raw session transcripts
- Account identifiers, balances, positions, or operational state
- Unreviewed model output presented as fact
- Temporary runtime details, local paths, or machine-specific state

## Promotion Rule

A private memory becomes public kbrain material only after it is rewritten as a
standalone page, checked against public sources, and reviewed under the
[Publication Boundary](../../decisions/publication-boundary.md). Raw agent memory
is never copied wholesale.

## Corrections

When a durable claim changes, update the canonical page and keep the correction
or retraction visible beside the superseded claim.
