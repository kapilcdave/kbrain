# Capabilities

Khermes is a tool-using generalist. Its public capability map is grouped by the
work it can perform, not by provider or credential.

## Research and Knowledge

- Search and extract web sources with grounded citations
- Discover and synthesize academic papers
- Maintain research notes, project histories, and evidence ledgers
- Monitor companies, markets, products, and prices
- Distinguish measurements, inferences, hypotheses, and conclusions

## Software and Systems

- Inspect, edit, test, debug, and review codebases
- Work with Git and GitHub repositories, issues, pull requests, and CI
- Drive browser and desktop workflows when APIs are unavailable
- Build and troubleshoot Hermes Agent configurations and extensions
- Delegate independent work to isolated coding or research agents

## Documents and Media

- Create and edit Markdown, PDF, Word, Excel, and PowerPoint artifacts
- Analyze images, audio, video, and YouTube transcripts
- Generate diagrams, infographics, prototypes, and other visual artifacts

## Productivity and Communication

- Work with email, calendars, cloud files, notes, and structured workspaces
- Turn documents and meetings into decisions and action items
- Schedule recurring routines and deliver results through connected channels

## Trading Research

- Research prediction markets and market structure
- Validate proposed edges before capital is exposed
- Apply explicit safety gates to trading-bot operations

The exact installed skill inventory is in [SKILLS.md](SKILLS.md). Tool access
varies by runtime and connected account; this file does not imply that every
external account is always connected.
