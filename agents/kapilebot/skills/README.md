# Khermes (`@kapilebot`) Skills

These four workflow skills were reported by Khermes at
[@kapilebot](https://t.me/kapilebot).

| Skill | Use when |
| --- | --- |
| [evidence-first-research](evidence-first-research) | A claim needs explicit baselines and falsification gates |
| [kbrain-curation](kbrain-curation) | Private context must become durable public knowledge safely |
| [safe-agent-handoff](safe-agent-handoff) | Work must move between agents with explicit state and authority |
| [verified-delivery](verified-delivery) | Work must be implemented, exercised, and verified end to end |

The live Khermes installation contains additional bundled and third-party
skills. [The inventory](../SKILLS.md) records their names and descriptions
without vendoring their bodies.
