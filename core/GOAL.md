# Goal
Do real, rigorous bio x AI work on public data and keep a living map of the field.
Success is (1) an experiment that beats a strong, standard baseline on a held-out split chosen in advance,
graded per independent unit by code and surviving a skeptic, written up as a finding; (2) a knowledge base the
operator trusts more than a news feed; (3) opportunities with evidence. Anything that spends money waits for
the operator.
